# 心愿小镇数值设计工具

加工配方与订单设计工具，使用 GitHub Pages 发布。

计算在浏览器本地执行，导入文件不会自动上传。`orders/shared-session.json` 是用户明确同步到仓库的配置与经营存档快照。

- processing 使用 Pyodide 0.28.3 保留原 Python 排程和校验逻辑。
- Excel 构造保留原导出器公式及样式，使用 openpyxl 打包。
- 生产链路沿用原商品、建筑双视图模板。
- orders 保留逐级订单配置和拟合功能。

## 订单工具当前版本

- 牧场需求组：每级自动列出全部同建筑与高级加工链组合，默认按商品组合展示（可手动展开 A/B/C/D 排列），自动联合计算四单优化时间；相同交付需求复用排程并正确重映射动物位。支持分类、建筑/主链、商品筛选、分页、排序、联合排程详情和完整JSON导出。
- 牧场求解结果按项目完整数据、等级、需求规则、产能分别缓存于本地IndexedDB；已证明最优才显示确定的优化时间，否则显示上下界。不修改普通订单项目。观察项保留累计工时、复杂度和商品金币总值。
- 普通订单在全部等级面板、全部等级配置和单等级分析中显示平均金币奖励，按最终生成概率加权，沿用商品金币总值×5；缺少单价时明确提示。
- 本站修改经验证后直接同步 GitHub；浏览器内项目和经营存档仍需显式备份或同步。

- 全部等级面板、逐级参数配置、单等级订单分析；商品种类和来源均保留原始输入权重，概率精度全局统一。
- 累计工时均值下方提供拟合前等概率均值：本级全部候选逐单等概率的平均工时，不应用种类或来源拟合目标；单级与全等级配置均可查看。
- 导入加工链路 Excel 的商品、配方、时间、累计土地与金币单价。价格按商品ID匹配，保留“配置值/含估算”等状态；缺失价格不按0处理。
- 普通订单与牧场商品支持悬浮/键盘焦点查看详情，包含每批配方的原料名称、数量、产出及时间、复杂度和单价；单品信息和商品列表显示金币单价，支持排序；JSON保留价格数据，CSV包含订单商品金币总值。商品价值与订单奖励分开。
- 按当前最终拟合概率模拟刷新订单，不检查仓库。
- 固定等级的场景模拟经营：点空地弹出作物盘、按住拖动连续播种/收割并在松开时结束本轮操作，再点空地重新选作物、直接选择作坊商品与查看材料、并行生产、默认4个共用队列格，等待、制作及完成品共用；成品点击收获入库。商品按钮仅名称和库存，选中后展示时间与材料库存/需求，仓库收获漂字、满仓拦截、免费换单及仓库升级。
- 开局给所有已解锁商品的2倍单次订单需求，支持1/2/3倍并随订单数量变化；播种免费。交单奖励为所交商品金币总值×5，缺价格时提示补导入，不用工时冒充价值。旧规则经营存档独立保留。
- 订单按钮为“交付/刷新”；需求与库存数字加粗，备齐显示绿色，缺货显示红色，统一显示库存/需求。
- 游戏时间与现实1:1，支持离线结算、GM跳过1小时和独立自动存档；试玩经济规则可调整，不改订单拟合参数。

从首页进入订单工具时，已有浏览器项目优先恢复。首次打开自动读取 `orders/shared-session.json` 中的已同步配置与经营存档；没有同步快照时，首页入口仍可读取仓库中的数值表。顶部“备份 / 恢复”支持下载完整备份、恢复文件或显式使用已同步配置，恢复前会备份现有数据。

本次快照包含35种商品、20级原始配置、万分制精度和2份经营存档；包含配方、商品金币价值、累计土地、原始种类/来源权重、仓库、金币和生产队列。拟合结果按配置重新计算。它是一次性同步快照，后续浏览器中的修改不会自动写入GitHub。
