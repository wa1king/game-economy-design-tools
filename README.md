# 心愿小镇数值设计工具

加工配方与订单设计工具，使用 GitHub Pages 发布。

计算在浏览器本地执行，导入文件不会自动上传。`orders/shared-session.json` 是用户明确同步到仓库的配置与经营存档快照。

- processing 使用 Pyodide 0.28.3 保留原 Python 排程和校验逻辑。
- Excel 构造保留原导出器公式及样式，使用 openpyxl 打包。
- 生产链路沿用原商品、建筑双视图模板。
- orders 保留逐级订单配置和拟合功能。

## 订单工具当前版本

- 牧场“同建筑”订单组排除所有作物，田地来源和带作物标记的商品不会作为交付项进入同建筑候选；非作物仍支持重复2—4位。高级加工链规则及配方原料保留，列表、导入重算、全等级统计共同生效；继续复用有效的非作物排程缓存与既有数量设置。


- 普通订单的同建筑排除规则对田地作物豁免：允许多种田地作物同单，也允许两种作物搭配加工品；其他同建筑商品与直接上下游仍排除，单商品最近10级窗口保留。刷新后按现有参数重新生成候选，需重新拟合。


- 全部等级配置支持点击数值列头选整列、点击等级选整行、点击左上角选全部，分组标题可选字段组，Shift+点击列头/等级可选连续多列/行；也支持拖选或 Shift+单击选区、Ctrl+C 复制输入原值、Ctrl+V 粘贴 Excel/TSV 数值矩形，单值可填满选区。仅处理数值输入列，忽略格式与显示占比；空白保留，未开放单元格跳过，越界/无效值整次拒绝。批量修改按等级一次递增版本并使旧拟合结果失效，保留 Ctrl+Enter 向下填充。


- 牧场顶部新增“全等级分布”：按同建筑 / 高级加工链对比各级联合优化时间、累计工时箱线图，查看单级每半小时分段占比和逐级最小/中位/平均/最大值，CSV含P25/P75。每组等权、不计排列，读取已保存数量/产能；优化时间仅统计已证明组合并显示覆盖数量。支持补算全部等级、暂停续算与相同需求同产能的排程复用，不改普通订单或自动上传用户数据。

- 同建筑四个动物位始终允许重复商品，覆盖 AABC、AAAB、AABB、AAAA；单商品建筑也可生成四单组合，按组合去重，数量仍可逐位调整并计算联合排程。“高级加工链允许重复商品”仅控制高级链；新规则使用独立缓存，不覆盖原数量配置。

- 牧场支持导入 Excel 或全等级重算 JSON。导入前独立备份旧来源与设置；相同商品/来源 ID 时保留已调整数量、目标与产能，按新配方重算全部等级后再切换数据。缓存按完整新来源隔离，不沿用旧配方的排程或最优标记；导入文件与结果不会自动上传。

- 牧场以方案浏览为主：同建筑按建筑→方案切换，高级加工链按建筑→最终产品→方案切换；分类、建筑、最终产品和方案标签统一位于左侧，支持标签点击、方向键切换与随机查看，保存浏览位置。主界面同屏展示四个交付数量、联合优化时间/累计工时/复杂度/金币和共同加工链。
- 主图默认紧凑排布并适配图区，同工坊同色，保留全部共同上游与配方；可切换回按解锁等级的原链路图。联合排产明细直接展示在加工链图下方并随方案联动；配量目标、完整清单与统计默认折叠。后台进度不重置当前图的缩放与滚动，附表搜索不筛掉主浏览器方案。

- 牧场共同加工链沿用生产链路模板：按建筑解锁等级、ID固定配色，同工坊同色；横向经济加工级数、纵向商品解锁等级，建筑在真实解锁级标星。原料主干合并，真实分叉加点、无关交叉跨线；箭头标每件配方用量，节点保留总生产、交付和消耗。列表展开与详情共用，支持冻结表头、缩放和适应宽度。
- 牧场支持手动改交付数量、本组及当前筛选批量配量。默认联合优化时间6小时±30分，在时间范围内优先接近同一级共同累计工时目标；目标、数量上限可改，逐级保存并支持还原数量。共同累计工时留空时按本级排程估算。
- 配量是有预算的候选搜索，逐候选复核四单联合排程；不宣称全局最优数量。仍严格区分已证明最优时间与可行上下界。加工瓶颈导致累计工时目标无法达到时给出理论上界说明。
- 订单清单显示目标偏差和筛选范围内累计工时均值、范围。数量、建议、目标与排程本地缓存，完整JSON导出保留全部数据；预览只显示前8组摘要，避免大型排程卡住界面。

- 牧场需求组：每级自动列出全部同建筑与高级加工链组合，默认按商品组合展示（可手动展开 A/B/C/D 排列），自动联合计算四单优化时间；相同交付需求复用排程并正确重映射动物位。支持分类、建筑/主链、商品筛选、分页、排序、联合排程详情和完整JSON导出。
- 牧场求解结果按项目完整数据、等级、需求规则、产能分别缓存于本地IndexedDB；已证明最优才显示确定的优化时间，否则显示上下界。不修改普通订单项目。观察项保留累计工时、复杂度和商品金币总值。
- 普通订单在全部等级面板、全部等级配置和单等级分析中显示平均金币奖励，按最终生成概率加权，沿用商品金币总值×5；缺少单价时明确提示。
- 本站修改经验证后直接同步 GitHub；浏览器内项目和经营存档仍需显式备份或同步。

- 全部等级面板、逐级参数配置、单等级订单分析；商品种类和来源均保留原始输入权重，概率精度全局统一。
- 累计工时均值下方提供拟合前等概率均值：本级全部候选逐单等概率的平均工时，不应用种类或来源拟合目标；单级与全等级配置均可查看。
- 导入加工链路 Excel 的商品、配方、时间、累计土地与金币单价。新导入项目的农田来源默认权重为该级累计土地上限的一半（30→15），显示占比再与其他来源权重归一化。价格按商品ID匹配，保留“配置值/含估算”等状态；缺失价格不按0处理。
- 普通订单与牧场商品支持悬浮/键盘焦点查看详情，包含每批配方的原料名称、数量、产出及时间、复杂度和单价；单品信息和商品列表显示金币单价，支持排序；JSON保留价格数据，CSV包含订单商品金币总值。商品价值与订单奖励分开。
- 按当前最终拟合概率模拟刷新订单，不检查仓库。
- 固定等级的场景模拟经营：点空地弹出作物盘、按住拖动连续播种/收割并在松开时结束本轮操作，再点空地重新选作物、直接选择作坊商品与查看材料、并行生产、默认4个共用队列格，等待、制作及完成品共用；成品点击收获入库。商品按钮仅名称和库存，选中后展示时间与材料库存/需求，仓库收获漂字、满仓拦截、免费换单及仓库升级。
- 开局给所有已解锁商品的2倍单次订单需求，支持1/2/3倍并随订单数量变化；播种免费。交单奖励为所交商品金币总值×5，缺价格时提示补导入，不用工时冒充价值。旧规则经营存档独立保留。
- 订单按钮为“交付/刷新”；需求与库存数字加粗，备齐显示绿色，缺货显示红色，统一显示库存/需求。
- 游戏时间与现实1:1，支持离线结算、GM跳过1小时和独立自动存档；试玩经济规则可调整，不改订单拟合参数。

从首页进入订单工具时，已有浏览器项目优先恢复。首次打开自动读取 `orders/shared-session.json` 中的已同步配置与经营存档；没有同步快照时，首页入口仍可读取仓库中的数值表。顶部“备份 / 恢复”支持下载完整备份、恢复文件或显式使用已同步配置，恢复前会备份现有数据。

本次快照包含35种商品、20级原始配置、万分制精度和2份经营存档；包含配方、商品金币价值、累计土地、原始种类/来源权重、仓库、金币和生产队列。拟合结果按配置重新计算。它是一次性同步快照，后续浏览器中的修改不会自动写入GitHub。
